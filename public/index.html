03

Penggunaan

Kirim permintaan GET ke endpoint yang diinginkan dengan parameter berikut:

message: Isi permintaan kamu
04

Respon

Response diberikan dalam format JSON seperti berikut:

{
  "status": 200,
  "creator": "Navy",
  "data": {
    "response": "Hasil permintaan kamu"
  }
}
05

case 'ai4': {

  var res = await fetchJson(`https://rest-api-wine.vercel.app/ai4chat?text=${q}`)
